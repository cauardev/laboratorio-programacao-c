## ⚙️ Como compilar e executar

> [!NOTE]
> É necessário ter o compilador **GCC** instalado.

```bash
cd aula-14-matrizes
gcc exercicio_matriz.c -o exercicio_matriz
./exercicio_matriz
```

> [!TIP]
> No Windows, execute com `exercicio_matriz.exe`. Para as outras aulas, basta entrar na pasta correspondente e trocar o nome do arquivo.
